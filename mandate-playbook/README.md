# Mandate Playbook

This project uses the supplied `Mandate Playbook.html` as its exact application
entry point. The bundled page contains its design system, fonts, application
logic, sample data, and interactions in a single self-contained `index.html`.

It includes role-based behavior, task analytics, Board, List and Timeline
views, checklist creation, task drawers, ownership controls, filters, and
drag-and-drop task movement.

No database or external service is connected. Changes made while using the
prototype remain in browser memory for the current session.
